⚙️ Tech Stack & DevOps Workflow

Django & Wagtail

Full-stack development with Django, content management via Wagtail, using formsets, HTMX and Chart.js for the dynamic front end.

VPS Deployment

Hosted on an Infomaniak VPS (Ubuntu 24.04), with Nginx as reverse proxy, Gunicorn as application server and PostgreSQL as the database.

Security & SSL

Full HTTPS setup via Let’s Encrypt, Infomaniak firewall management, 301 redirects, and a strict cookie policy (CSRF, secure sessions).

Workflow & DevOps

Deployment via Git & SCP, isolated virtual environment, automated collectstatic, and Gunicorn/Nginx restarts via systemctl.

Tools & IDE

Development in PyCharm and TablePlus for the database. Testing and code coverage with pytest and coverage.

CI/CD & Monitoring

Future use of GitHub Actions for CI/CD, with application monitoring via Nginx and Gunicorn logs.
